Graphghan

Charts for pixel-chart crafts

Graphghan composes crochet and cross-stitch charts from motifs defined in inches, validates them, and publishes them. This host serves the published pattern feed; work a pattern in the iOS app, or from the chart files below.

The feed

  • patterns/index.json — every published pattern
  • patterns/<slug>/pattern.json — one pattern's manifest: palette and every published chart
  • patterns/<slug>/chart.json, chart.png, written-rows.txt — the default chart
  • schema/ — the JSON Schemas the documents declare

The format is documented in docs/chart-format.md, with conformance fixtures any reader can test against.
