Graphghan

Charts for pixel crochet, and an app to work them in.

A hobby project in three parts: a toolkit that composes a blanket chart from motifs measured in inches, a published feed of the finished patterns, and an iPhone app that walks you through one stitch by stitch.

The app is in TestFlight beta. Not on the App Store yet.

The app

Built in SwiftUI for iOS 17 and later. It reads the pattern feed this site serves, keeps a project per blanket you start, and remembers exactly where you stopped.

Work screen
Full screen, one run at a time, with Done and Back as the only two things you need to hit.
Live Activity
The current row on the lock screen and in the Dynamic Island, so you can count without unlocking.
Progress per project
Every advance is stored, so the row you are on survives putting the phone down for a month.
Charts and written rows
The grid, or the written-out row instructions, from the same source document.

The format

Every chart is a JSON document: a palette, run-length rows, a gauge, and a technique that defines working order. It is documented, has JSON Schemas, and ships conformance fixtures, so the app is not the only thing that can read a pattern — anything you write can too.

This host serves the feed: patterns/index.json lists every pattern, and each one has a pattern.json manifest beside its chart files.
