# Chart-format conformance fixtures

Generated by `generate.py` (run `uv run python fixtures/chart-format/generate.py`); a test fails if
the committed files differ from a fresh generation. Every reader of the chart format (the Python
package, the PWA, the iOS app) is expected to:

- validate each `*.chart.json` against `schema/chart.schema.json`;
- produce exactly the passes in `<name>.sequence.json` (`{"passes": [...]}`), or the same SHA-256
  of the canonical JSON of its pass list (`{"sha256": "..."}`), where canonical means keys sorted,
  no whitespace, UTF-8;
- refuse to sequence a chart that has no `*.sequence.json` (unknown technique, no passes) while
  still decoding it for display;
- reproduce `<name>.progress.expected.json` from `<name>.progress.json` (see docs/chart-format.md).
